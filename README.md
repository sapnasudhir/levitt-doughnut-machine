# Levitt doughnut machine (1920)

An interactive, hand-inked isometric figure of a doughnut machine like the one Adolph Levitt built in 1920 for his Harlem bakery window.

**Live:** https://sapnasudhir.github.io/levitt-doughnut-machine/

Light the burner, start the conveyor and drop batter: each ring fries, is turned over halfway, and rides up the exit ramp onto the drain tray. Drag to turn the machine round; switch on See-through and Labels to see the burners, motor, gearbox, chains and plunger inside.

The overall process follows historical accounts; the internal parts are a reconstruction, not drawings of the original.

Sources: [Smithsonian](https://www.smithsonianmag.com/history/the-history-of-the-doughnut-150405177/) · [Allegra Lab](https://allegralaboratory.net/mass-produced-desire-and-the-machine-made-doughnut) · [Logically Facts](https://www.logicallyfacts.com/en/fact-check/true-in-1920-russian-born-immigrant-adolph-levitt-created-the-first-automated-doughnut-machine) · [JUF](https://www.juf.org/jewish-chicago/donuts-the-hole-jewish-story/)
